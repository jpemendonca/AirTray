First public version.

**English**
- Tray flyout with power, target temperature and Cool / WindFree / Economy / Sleep shortcuts.
- Main window with every control the unit reports, maintenance (filter, self-check) and settings.
- Portuguese and English, light and dark theme, single instance, start with Windows.
- Download `AirTray-*-win-x64.zip`, unzip, run `WindFreeControl.exe` and paste a SmartThings token
  (see the README). The exe is not code-signed: on the SmartScreen warning choose
  More info → Run anyway.

**Português**
- Painel na bandeja com liga/desliga, temperatura e atalhos Resfriar / WindFree / Econômico / Sono.
- Janela principal com todos os controles do aparelho, manutenção (filtro, autodiagnóstico) e
  configurações.
- Português e inglês, tema claro e escuro, instância única, iniciar com o Windows.
- Baixe o `AirTray-*-win-x64.zip`, extraia, rode o `WindFreeControl.exe` e cole um token do
  SmartThings (veja o README). O exe não tem assinatura: no aviso do SmartScreen clique em
  Mais informações → Executar assim mesmo.
